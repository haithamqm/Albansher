# البنشر الذكي
منصة عربية RTL لخدمات الإطارات والمركبات، تتضمن صفحة عامة، واجهة طلب خدمة، تسجيل مقدم خدمة، ولوحة إدارة للهوية والإعلانات والطلبات.

## نشر Railway
1. ارفع محتويات هذا المجلد إلى مستودع GitHub الحالي (استبدل الملفات القديمة بعد حفظ نسخة احتياطية).
2. اربط خدمة Railway بالمستودع نفسه، واضبط Build/Start حسب `railway.json` و`npm start`.
3. اضبط المتغيرات في خدمة التطبيق:
   - `NODE_ENV=production`
   - `ADMIN_BOOTSTRAP_EMAIL` بريد المدير
   - `ADMIN_BOOTSTRAP_PASSWORD` كلمة مرور قوية
   - `ADMIN_SESSION_TOKEN` رمز دخول عشوائي طويل وفريد
   - `JWT_SECRET` سر عشوائي طويل وفريد (لا تشاركه)
4. **قاعدة البيانات:** هذه النسخة لا تتطلب PostgreSQL لبدء التشغيل التجريبي؛ إذا لم يوجد `DATABASE_URL` فإنها تعمل بوضع JSON محلي. هذا مناسب للتحقق الأولي فقط، وقد تفقد البيانات عند إعادة النشر أو نقل الحاوية. لا تعتمدها تجاريًا قبل إضافة تخزين دائم/تكامل PostgreSQL فعلي.
5. افتح `/health` للتحقق من أن الخادم يعمل، ثم `/` و`/customer` و`/provider` و`/admin`.

## تحذيرات قبل الاستخدام الفعلي
- لا تترك بيانات المدير الافتراضية. عيّن `ADMIN_BOOTSTRAP_EMAIL`, `ADMIN_BOOTSTRAP_PASSWORD`, و`ADMIN_SESSION_TOKEN` بنفسك في Railway.
- هذا إصدار تأسيسي قابل للنشر والاختبار، وليس نظامًا تجاريًا مكتمل الاعتماد. لا يحتوي بعد على OTP/SMS فعلي، أو دفع إلكتروني، أو رفع آمن لوثائق الهوية، أو Web Push، أو تتبع خلفي مضمون، أو قاعدة بيانات PostgreSQL موصولة بالكود. لا يُستخدم لتخزين بيانات حساسة أو تشغيل عمليات ميدانية قبل استكمال واختبار هذه الأجزاء.
- بعض واجهات إدارة الطلبات الحالية مخصصة للاختبار؛ يلزم ربط صلاحيات موحدة لكل مسارات الإدارة قبل الإنتاج العام.
