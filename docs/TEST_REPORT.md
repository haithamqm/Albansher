# تقرير الاختبارات — البنشر الذكي

تاريخ إعداد التقرير: 2026-10-10

## اختبارات نُفذت في بيئة العمل الحالية

- `node --check src/server.js`: ناجح.
- `node --check src/db.js`: ناجح.
- `node --check src/auth.js`: ناجح.
- `node --check public/app.js`: ناجح.
- استخراج مخطط SQL وتشغيله على SQLite في الذاكرة باستخدام Python: ناجح.
- `PRAGMA foreign_key_check` على المخطط الجديد: لا توجد مخالفات.
- خمسة اختبارات ثابتة في `npm test`: ناجحة.
- تحقق مخطط قاعدة البيانات من وجود حجز المخزون للمنتجات: ناجح.
- فحص ثابت للمشروع والواجهات والمسارات الأساسية: مُضاف إلى `npm test`، ويحتاج تشغيله في بيئة ثُبّتت فيها تبعيات Node.

## اختبارات لم يمكن تنفيذها هنا

تثبيت حزم npm تعذر بسبب خطأ DNS/اتصال بمستودع npm (`EAI_AGAIN registry.npmjs.org`). لذلك لم يُشغّل خادم Express ولم تُنفذ اختبارات HTTP تكاملية أو تدفق مستخدم كامل في هذه البيئة. لا يُعد فحص الصياغة أو مخطط قاعدة البيانات بديلًا عن هذه الاختبارات.

## يلزم قبل الإطلاق التجاري

1. `npm ci` أو `npm install` في بيئة اتصالها مستقر.
2. `npm test` ثم تشغيل الخادم واختبار `/api/health`.
3. اختبار تسجيل الدخول والأدوار واعتماد مقدم الخدمة وتوزيع الطلبات.
4. اختبار التزامن ومنع قبول الطلب نفسه مرتين، وتكرار إنشاء الطلب مع `Idempotency-Key`.
5. اختبار عروض الأسعار وموافقة العميل قبل بدء العمل.
6. اختبار المنتجات والمخزون وحجز الكميات وإعادتها عند الإلغاء، والطلبات التجارية، والرسائل والإشعارات.
7. اختبار النسخ الاحتياطي والاستعادة بعد إعادة التشغيل.
8. اختبار أمني مستقل وتجربة فعلية على Safari في iPhone وChrome في Android.
9. نشر تجريبي على Railway مع Volume دائم، ثم مراجعة السجلات.

## خدمات لم تُربط بعد

- OTP/SMS: يتطلب مزودًا ومفاتيح واعتمادًا وتكلفة.
- بوابة الدفع: لم تُربط؛ تغيير حالة الدفع يدوي إداري وليس إثباتًا لتحصيل إلكتروني.
- خرائط/ملاحة وتتبع خلفي مباشر: لم يُربط مزود خرائط أو تتبع مستمر.
- رفع الصور والوثائق إلى تخزين ملفات آمن: الحقول الحالية تعتمد روابط صور؛ لم يُنفذ رفع الملفات.
- ذكاء اصطناعي خارجي لفهم اللهجات: غير مربوط؛ الأساس التشغيلي لا يعتمد عليه.
- إشعارات دفع نظامية: الموجود إشعارات داخل قاعدة البيانات وواجهات API؛ لا يوجد تكامل Push خارجي.

لا تُعامل هذه الوظائف على أنها مكتملة أو مختبرة.
