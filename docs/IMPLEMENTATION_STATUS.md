# سجل التنفيذ — البنشر الذكي 0.2.0

## نُفّذ في الشيفرة الحالية
- واجهة PWA متجاوبة، عربية/إنجليزية، RTL/LTR، ووضع فاتح/داكن.
- خادم Express وقاعدة SQLite، مع جداول للمستخدمين والأدوار والخدمات والمنتجات والعروض والطلبات وسجل الحالة والمحادثات والتقييمات والشكاوى والإعدادات والتدقيق والفروع وأنواع المركبات والإشعارات ومفاتيح منع التكرار.
- تجزئة كلمات المرور بـ bcryptjs، وجلسات JWT، وتحديد معدل طلبات API، وصلاحيات مفروضة على الخادم، وسياسة CSP أساسية.
- إنشاء حساب العميل ومقدم الخدمة، واعتماد مقدم الخدمة إداريًا، وإدارة الاستعداد والملف المهني والخدمات المقدمة.
- إنشاء الطلبات، والتحقق من الإحداثيات، ودعم مفتاح Idempotency-Key، ومنع إسناد الطلب الخدمي إلى أكثر من مقدم خدمة.
- حجز كمية المنتج عند إنشاء طلب المنتج وإعادتها للمخزون عند إلغاء الطلب إذا كانت محجوزة.
- حالات الطلب وعروض الأسعار وموافقة العميل قبل بدء العمل عند وجود عرض معلق أو مرفوض.
- محادثات مرتبطة بالطلب وإشعارات داخلية وقراءة الإشعارات والتقييمات والشكاوى.
- إدارة الخدمات والمنتجات والعروض والطلبات وحالة الدفع الإدارية والفروع وأنواع المركبات والإعدادات من خلال API؛ واجهة الإدارة تعرض الخدمات والطلبات والشكاوى ومقدمي الخدمة وتتيح إضافة منتجات وعروض وخدمات وفروع وأنواع مركبات.
- تقرير ملخص إداري، وسجل تدقيق، ونقطة فحص صحة، وملفات Railway وDocker، وأداة نسخ احتياطي لقاعدة SQLite.
- اختبارات ثابتة باستخدام Node.js test runner.

## اختبارات نُفذت
- فحص صياغة ملفات JavaScript الأساسية: ناجح.
- تشغيل الاختبارات الثابتة `npm test`: 5 اختبارات ناجحة.
- اختبار إنشاء مخطط SQL على SQLite في الذاكرة والتحقق من العلاقات الخارجية: ناجح.
- لم تُنفذ اختبارات HTTP متكاملة لأن تثبيت حزم npm تعذر بسبب فشل DNS للوصول إلى registry.npmjs.org. التفاصيل في `TEST_REPORT.md`.

## ما يزال مطلوبًا قبل الإنتاج
- تثبيت التبعيات وتشغيل خادم Express واختبار تدفقات HTTP فعليًا.
- اختبار end-to-end كامل للعميل ومقدم الخدمة والإدارة، واختبار الضغط والتزامن والأمان.
- تكامل OTP/SMS فعلي، واستعادة كلمة المرور، وإشعارات Push نظامية.
- تكامل دفع إلكتروني، وتكامل خرائط/ملاحة وتتبع خلفي مباشر.
- رفع صور ووثائق آمن إلى تخزين ملفات دائم، بدل الاكتفاء بروابط صور.
- تكامل ذكاء اصطناعي اختياري لفهم اللهجات، دون جعله شرطًا لإنشاء الطلب.
- نقل إنتاجي إلى PostgreSQL عند الحاجة إلى التوسع، أو إثبات ملاءمة SQLite مع تخزين دائم ونسخ احتياطي.
- اختبار فعلي على iPhone وAndroid، ونشر تجريبي على Railway وربطه بمستودع GitHub.

لا تعتبر أي نقطة في قائمة المطلوب مكتملة قبل تنفيذ اختبار يثبتها.
